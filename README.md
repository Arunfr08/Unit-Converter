# Java Unit Converter

A console-based **Unit Converter application built using Java** that allows users to convert values between different units of measurement. The project demonstrates fundamental Java programming concepts, including methods, switch statements, loops, input validation, and user interaction through the console.

## Features

The application supports six conversion categories:

- **Length:** Kilometers, meters, centimeters, and millimeters.
- **Weight:** Kilograms, grams, and milligrams.
- **Temperature:** Celsius, Fahrenheit, and Kelvin.
- **Time:** Hours, minutes, seconds, and milliseconds.
- **Digital Storage:** Gigabytes (GB), megabytes (MB), and kilobytes (KB), using decimal conversion units.
- **Speed:** Kilometers per hour (km/h), miles per hour (mph), and meters per second (m/s).

### Additional Features

- Menu-driven interface for easy navigation.
- Separate methods for each conversion category.
- Input validation for numeric values and menu choices.
- Repeated conversions without restarting the application.
- Option to return to the main menu from each category.
- Formatted output using `System.out.printf()`.
- Support for decimal values.

## Technologies Used

- **Language:** Java
- **Input Handling:** `Scanner`
- **Core Concepts:** Methods, loops, switch statements, conditional statements, and exception-resistant input validation.

## How to Run

### Prerequisites

- Java Development Kit (JDK) installed.
- A terminal or Java-compatible IDE, such as IntelliJ IDEA or Visual Studio Code.

### Steps

1. Clone this repository or download the source code.
2. Open a terminal in the directory containing `UnitConverter.java`.
3. Compile the program:

   ```bash
   javac UnitConverter.java
   ```

4. Run the application:

   ```bash
   java UnitConverter
   ```

5. Select a conversion category, enter your choice, and follow the on-screen instructions.
